Browser image editor

Pict

A privacy-friendly image editor that runs entirely in the browser, with real selections, layers, drawing, transforms, adjustments and export workflows.

Visit Pict ↗
What it is

A capable image editor that never needs your image to leave the browser.

Pict is the visual-asset tool in Gantry. It is a browser application rather than a self-hosted server, and ordinary editing happens locally in the page without requiring an account or uploading the image to a Gantry service.

The editor goes well beyond a crop-and-filter demo. Selection workflows include rectangle, ellipse, lasso, magic wand, colour-based selection, invert, feather and resizing. Layers, masks and adjustment layers provide non-trivial composition, while brush, pencil, line, fill, clone, eraser, eyedropper, text, crop and transform tools cover direct editing.

Export is treated as its own quality decision. Fast browser-native resizing, quality-oriented resampling and pixel-art handling let users choose the right trade-off rather than assuming every image should go through the same export path.

What you get

Useful capability without mandatory complexity.

The project stays focused on its own job; the surrounding Gantry tools remain optional.

Selections

Rectangle, ellipse, lasso, magic wand, colour selection, opaque-pixel selection, feathering and selection transforms support targeted edits.

Layers & masks

Reorder, rename, merge and flatten layers, use masks and adjustment layers, and transform layer content without flattening the whole image first.

Drawing & editing

Brush, pencil, line, fill, clone, eraser, eyedropper, text and direct transform/crop workflows make Pict useful for real website assets.

Privacy & export

Keep the image client-side and choose export modes appropriate for speed, photographic quality or pixel art.

Typical workflow

Start with the shortest path.

Advanced deployment or integration features appear only when the workflow actually needs them.

  1. 01

    Open pict.ink directly—there is no account and no my.* instance choice because Pict is not a persistent self-hosted service.

  2. 02

    Load an image, use selections/layers or direct drawing tools as needed, and keep edits in the browser.

  3. 03

    Export the finished asset in the mode that fits the source material.

  4. 04

    Place the result into a Nift or any other web project; Pict does not require the site to be built with Gantry tooling.

Inside Gantry

Connections that remove real hand-off friction.

Each product already owns one side of these workflows. The integration exists to remove duplicate navigation, setup or context.

Works with

Nift

This is the most natural Pict connection: prepare or retouch the images a site needs, then reference those ordinary files from Nift templates/content. There is no runtime coupling and no special asset protocol.

Access

No instance launcher is needed.

Pict is an interactive public browser application rather than a persistent self-hosted service, so there is no zero/one/many instance problem to solve. Open pict.ink directly.

The planned my.gantry.cv app drawer can still include Pict as a first-class tile; it simply links straight to pict.ink while the self-hosted applications link to their my.* instance launchers.
