Gantry Tools

Projects

Focused tools for creating, building, developing and operating the web. Every project is useful independently; integrations exist where they remove a real hand-off, duplicated setup or missing piece of context.

Create & build

From source material to deployable output.

Pict handles image work; Markup++, Jsonic++, Nift and Minify++ cover authored content, structured data, site generation and optimization. TSCC and JS++ explore compiler/runtime territory for TypeScript and embeddable JavaScript.

Develop & operate

From code to running systems.

Cortex and Warden provide agent-assisted and remote development, Trestle provides the backend, Watchpost watches machines/fleets, and Webfleet watches the public web/API surface.
